# HeliBoard_th

**HeliBoard เวอร์ชันที่แก้ไขปัญหาการพิมพ์ภาษาไทย**

โปรเจกต์นี้เป็น fork ของ [HeliBoard](https://github.com/HeliBorg/HeliBoard) ปรับแก้เพื่อให้ประสบการณ์พิมพ์ในภาษาไทยดีมากขึ้น
> ส่วนที่แก้ไขทำงานเฉพาะตอนพิมพ์ภาษาไทย ภาษาอื่นทำงานเหมือน HeliBoard ต้นฉบับ
